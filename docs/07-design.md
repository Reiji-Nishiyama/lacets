# 07. デザイン

UI の世界観と、画面をつくるときの約束事。見本（統合案）は claude.ai のデザインキャンバス
「Lacets デザイン 3 案」（開発者本人のプライベートなページ）の最下段。

## 世界観
- **冒険の地図帳**: ワンダーフォーゲル・ランドネ・Casa・BE-PAL のような、自然を感じる解放感と「冒険への扉」のわくわく感
- **余白とゆとり**: 情報を詰め込まない（楽天市場のような窮屈な画面はしない）。1 画面で伝えることを絞る
- **明るい背景**: 空色の地に、白い面を置く
- **使う場面**: iPad・ノート PC が中心。走行中は 1〜2 m 離れて、汗をかきながら見る

## 色（`src/ui/index.css` の変数）
| 名前 | 値 | 使いどころ |
|---|---|---|
| `--sky` | #E3F1F8 | 背景（空） |
| `--sky-deep` / `--meadow` | #B9DDEB / #8CC3B0 | 遠い山・近い山、勾配の塗り |
| `--pine` | #2C5F4F | 主要な線、選択、良い状態（ゴーストより速い） |
| `--sun` | #F4B63C | いちばん大事な操作（走りはじめる）、現在地 |
| `--ink` / `--ink-muted` | #24343B / #3B5560 | 文字 / 補助の文字（白・空の上で 4.5:1 以上） |
| `--paper` | #FFFFFF | 面 |
| `--leaf` | #EEF6EA | 札・控えめなボタン |
| `--relief-0`〜`5` | #E6F2E2 → #6DAF86 | 標高の帯（地図・勾配図で共通。低い → 高い） |

- 黄色（`--sun`）の上の文字は `--ink`。黄色の文字は使わない（白地でコントラストが足りない）
- 状態は色だけで示さない（文字・形と組み合わせる）

## 文字
- **Zen Maru Gothic**（500 / 700 / 900、`@fontsource/zen-maru-gothic` で同梱。オフラインでも表示できるよう、使った分は Service Worker でキャッシュ）
- 見出しは 900、ラベルは 700、本文は 500
- 走行中の数字: パワーが最大（84px 前後）、勾配・速度・ケイデンス・心拍が次（44px 前後）。`font-variant-numeric: tabular-nums`

## 形と余白
- 角の丸み: 大きな面 32px / パネル 24px / 操作 16px / 札 999px（丸）
- 余白: 8 の倍数（8, 16, 24, 32, 48）
- 操作の大きさ: 44px 以上。「走りはじめる」は 56〜72px
- 影や枠線はほとんど使わず、地の色の差で面を分ける。お知らせも色の帯ではなく地の色で区別する

## 部品
- **ボタン**: 既定 = 若葉色の地（控えめな操作）、`button-primary` = 太陽の黄色（画面に 1 つ、いちばん大事な操作）、`button-subtle` = 地なし（終了・削除など）
- **タブ**: 丸い札。選択中は白い地
- **札（badge）**: 丸い白い地に、状態の丸印（緑 = 接続済み、黄 = 接続中・再接続中、灰 = 未接続）
- **空の帯**（`SkyBackdrop`）: 画面上部に太陽と 2 重の山並み。装飾なので読み上げない

## ロゴ
- 形は `src/ui/brand/logo.ts` にだけ書く。ファビコン・PWA アイコン・README 用の画像は `npm run brand` で書き出す（`public/` の SVG が古いとユニットテストが失敗する）
- **バッジ**: 円の中に山と太陽、山肌を登るつづら折りの白い道。自転車ありは、ふもとをランドナー（泥除け・フロントバッグ・ドロップハンドル）で走る人
- **ロゴ文字**: 筆記体の「Lacets」を 1 本の峠道として描く（緑の道・白い縁・白い破線の中央線）。濃い地では空色の道に緑の中央線。小さく使うときは中央線を消す
- 使い分け: 自転車は 32 px 以下で読めないので、ファビコン・タブ・ヘッダー・ホーム画面のアイコンは**自転車なし**。ルートが空のときの案内、README、セットアップガイドの表紙など大きく見せる場面は**自転車あり**
- ヘッダーはバッジ＋ロゴ文字（h1 の読み上げは「Lacets」）。PWA の maskable と iOS のホーム画面は、円で切り抜かずに風景を全面に描いた四角

## 画面の構成（統合案）
- **ルートの事前確認**（`src/ui/routes/RoutePreviewPage.tsx`）: 空の帯の上にルート名と一言（「標高 ○ m から ○ m へ」）。その下の白い面を「情報（左 7）」と「出発（右 5）」に分ける
  - 左: 数字のチップ（距離・のぼり・くだり・最大勾配）→ 印の列 → 勾配図と開始地点のスライダー → 逆方向・ゴースト（設定として下に置く）
  - 右: 標高で塗り分けた地図（`RouteMap` の `relief`）。左上に路上画像のカバー率のピル、出典は「i」に畳む。その真下に幅いっぱいの「走りはじめる」。未接続なら「まずトレーナーにつなぎます」と「トレーナーに接続」
  - 幅 900 px 以下は 1 列（地図とボタンが下）
- **ルート一覧**（`src/ui/routes/RoutesPage.tsx`）: 空の帯の上に「ルート」と一言。カードの格子（幅 300 px 以上で自動で列を増やす）。先頭は取り込みのタイル。カードはルートの形の絵（`RouteThumbnail`、地図タイルなし。ヘアピンの峠は「ヘアピン ○」の札）、名前、チップ（距離・のぼり・平均・最大。平均勾配は始点と終点の標高差 ÷ 距離）。削除は絵の右上の白い札
- **走行履歴**（`src/ui/history/`）: 白い面の左に月のカレンダー（走った日は緑の丸、選んだ日は黄色、2 回以上は件数の札）と月の合計（回数・距離・のぼり・時間）、右にその月（または選んだ日）の走行を 1 回 1 行。行は日付の札（「10/25」を大きく、年と時刻を小さく）とルート名・チップ（距離・のぼり・時間・平均パワー・ゴースト）。同じルートを何度も走るので、形の絵を繰り返すカードより、日付と数字を縦に見比べやすい行にしている
- **走行の詳細**: 事前確認と同じ見出し（戻る札・ルート名・日時）。白い面の上段は左に数字（距離・経過時間・平均パワー・平均速度・獲得標高）と書き出し、右に地図（ルートは淡い緑、走った軌跡を濃い緑で重ねる。ルートが削除されていれば軌跡だけ）。下段は区間比較
- **デバイス**（`src/ui/connection/DevicesPage.tsx`）: 上の白い面の左がトレーナー（パワー 64px・ケイデンス・心拍 44px、未接続なら太陽の黄色の「トレーナーに接続」）、右が心拍計（任意）。その下に「負荷のテスト」の見出しと白い面（勾配を手で送る・勾配テストの記録）。シミュレータの設定は半透明の面で最後に
- **設定**（`src/ui/settings/`）: 1 枚の白い面を話題ごとの段（ライダーと自転車、勾配の再現度、トレーナーの負荷補正、地図・路上画像）に分け、左に見出しと説明、右に項目。段の間は若葉色の細い線
- 見出しは `page-hero`（`page-hero-title` 52px、900 px 以下 40px、600 px 以下 34px）、白い面は `sheet` で共通。電話の幅ではタブを見出しの下の 1 行に回す
- **走行中**（`src/ui/ride/RidePage.tsx`）: ヘッダー・空の帯は出さず、画面の高さいっぱいを使う
  - 上: 風景（路上画像 / 3D 地形 / 地図）。左上にルート名と状態、右上にゴースト差（先行なら太陽の黄色）、右下に小さな地図（ルートの形を SVG で描く。走った部分は濃い緑、現在地は黄色、ゴーストは灰色。地図の出典表示を隠さない位置）
  - 一時停止中・再接続中は、風景を淡くして中央に大きく状態と「再開」を出す（離れていても分かる）
  - 下の白い面: 印の列 → 数字（パワー 84px、他 44px）→ 経過時間・走行距離・残り、表示の切り替え、一時停止・終了
  - 大きな勾配図は出さない（進み具合は印の列で示す）。代わりに風景の左下に半透明（白 72%・ぼかし）の「この先 2 km」（`RideAheadProfile`）: 現在地から 2 km 先までを 250 m ごとの平均勾配で色分けし（`--grade-*`）、数字を載せる。次の印（ヘアピンなど）は点線と札、ゴーストは灰色の丸、右上に「次の 500 m 平均」。ゴールが近づくと右側が空き、ゴールに線と札
- **地図・勾配図のトーン**: 標高ごとに `--relief-*` で塗り分け、100 m ごとの白い等高線。ルートは白い縁取りの太い `--pine` の線、スタートは白、ゴールは `--sun` の丸

## 自己ベスト
- 対象は、ルートをスタートからゴールまで同じ向きで走り切った記録（前後 30 m の誤差は許す）。途中から・途中までの記録はタイムを比べられないので除く。逆方向は別に数える（`src/domain/ghost/personalBest.ts`）
- Lacets の走行のいちばん速い記録が「自己ベスト」、取り込んだ実走データのいちばん速い記録が「実走ベスト」
- 事前確認: 数字のチップの後ろに淡い黄色の「★ 自己ベスト 52:13」。押すとその記録をゴーストに選ぶ（選ぶと太陽の黄色）
- ゴーストの選択肢: 走り切った記録にはタイム、ベストには ★ を付けて先頭に
- 走行履歴: いまの自己ベストの回に太陽の黄色の「★ 自己ベスト」

## 印の列（走行中の進み具合）
ルートに合わせて切り替える（任意のルートにヘアピンがあるとは限らないため）。
| ルート | 印の意味 |
|---|---|
| ヘアピンがはっきりある峠（自動検出で 5 つ以上） | ヘアピン 1 つずつ |
| それ以外の登り | 標高 100 m ごと |
| 平坦 | 1 km ごと |

- 実装: `src/domain/course/progressMarkers.ts`。ヘアピンは前後 40 m の方位の差が 100° 以上の地点（100 m 以内の候補は 1 つにまとめる）。標高の印は始点から 150 m 以上登るルート。印は 30 個以下になるよう段を大きくする（標高 100 → 200 → 500 m、距離 1 → 2 → 5 km …）
- 越えた印は濃い緑、次の印は太陽の黄色、まだの印は薄い緑

## 文言
- 操作は何が起きるかをそのまま書く（「走りはじめる」「FIT ファイルを書き出す」）。同じ操作は流れの中で同じ名前
- やわらかい言葉づかい（「ゴーストといっしょに走る」）。エラーは何が起きたかと直し方を書く
